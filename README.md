 # Timetable Creation

This project is a simple **college timetable web page** created using **HTML and internal CSS**.  
It displays the **VI Semester Computer Science & Engineering timetable** in a clean, structured, and user-friendly format.

# Project Description

The timetable is designed for **Women’s Engineering College, Puducherry**, Department of Computer Science & Engineering.  
It includes:

- Day-wise schedule (Monday to Friday)
- Time slots from 9:15 AM to 4:45 PM
- Subjects with faculty initials
- Lab sessions, club hours, library, and sports periods
- A vertically aligned **Lunch** column

The layout is responsive and easy to read, making it suitable for academic use.


## 🛠️ Technologies Used

- **HTML5** – Structure of the timetable  
- **CSS3 (Internal CSS)** – Styling and layout design
